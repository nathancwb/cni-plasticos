Informações e configurações do painel

🔒 Alterando a Senha de Acesso

A senha do painel é definida via variável de ambiente no Vercel. Para alterá-la:

  • Acesse o dashboard do Vercel: vercel.com/dashboard
  • Selecione o projeto cni-plasticos
  • Vá em Settings → Environment Variables
  • Edite a variável ADMIN_PASSWORD
  • Faça um novo deploy para aplicar a mudança

🔧 Variáveis de Ambiente Necessárias

ADMIN_PASSWORD=sua_senha_secreta JWT_SECRET=string_aleatoria_longa_para_assinar_tokens GITHUB_TOKEN=ghp_seu_token_do_github GITHUB_REPO=nathancwb/cni-plasticos GITHUB_BRANCH=main

O JWT_SECRET pode ser qualquer string longa e aleatória. O GITHUB_TOKEN deve ter permissão de escrita no repositório (scope: repo).

💡 Como funciona o fluxo de edição

  • Você edita um produto no painel e clica "Salvar Produto"
  • O painel envia o arquivo produtos-data.js atualizado para a API
  • A API faz commit do arquivo no repositório GitHub via GitHub API
  • O Vercel detecta o novo commit e inicia um deploy automático (~1 minuto)
  • O site fica atualizado após o deploy concluir
